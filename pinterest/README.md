# 📥 Pinterest 投递箱

> **把图片丢进这个文件夹，然后告诉我「处理 pinterest 投递箱」。**
> 我会逐张看图、拆解视觉语言、匹配到仓库里的流派，生成笔记并归档。

## 用法

```
pinterest/                    ← 你把图丢这里（png / jpg / webp / gif 都行）
├── _已归档/                   ← 处理完的图会移到这里，避免重复处理
└── README.md                 ← 本文件
```

### 一次完整的回路

1. **丢图** —— 把 Pinterest（或任何地方）存的参考图复制进 `pinterest/`
2. **说一句** —— 「处理 pinterest 投递箱」
3. **我做这些**：
   - 逐张读图，拆解：主体 / 风格 / 光照 / 色彩 / 构图 / 媒介 / 情绪
   - 匹配仓库里 141 个流派中最接近的 1–3 个
   - 提取主色调，和流派卡的配色对比
   - 生成笔记到 `20-我的提示词/投递箱-<日期>.md`
   - 把图移到 `_已归档/`，原件保留
4. **你验收** —— 在 Obsidian 里看生成的笔记，不满意的直接改

## 为什么要有这个文件夹

Pinterest 的搜索是登录态的、个性化的——**你手动挑的图比任何爬虫抓的都准**。
爬虫只能按分类抓（见 [[Pinterest 抓取实战]]），而你能按直觉挑。

所以分工是：**你负责找图和判断，我负责拆解和归档。**

## 支持的格式

`.jpg` `.jpeg` `.png` `.webp` `.gif` `.bmp` `.tiff` `.heic`

## 注意

- 图**不会被删除**，只会移到 `_已归档/`
- `_已归档/` 里的图不会被重复处理
- 这些图**版权归原作者**，不要提交到公开仓库（已在 `.gitignore` 里排除）
